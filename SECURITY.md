# Security

This is an example app. It has no supported releases.

## Report a problem in this repository

Do not open a public issue for a security problem. Use GitHub's private vulnerability
reporting: go to the **Security** tab of this repository and select **Report a vulnerability**.

## Report a problem in Shopify

Report security problems in Shopify itself to Shopify's bug bounty program:
https://hackerone.com/shopify
